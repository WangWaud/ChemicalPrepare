# 实验室配方与实验流程

一个面向植物病理学实验室的静态网页工具，用于计算培养基、缓冲液和反应体系用量，并集中查阅实验 Protocol。

## 功能特点

- **培养基配方**：PDA/PDB、MM最小培养基、TSB/TSA、LB/LBA、R2A、KB、1/2 MS、V8等
- **消毒试剂**：HgCl₂、NaClO等消毒液配制与稀释计算
- **菌悬液制备**：Bm分生孢子悬浮液、细菌接种悬浮液浓度调节
- **代谢物处理**：12HEA等代谢物的母液配制与工作液稀释
- **母液配制**：Tween-20、常用抗生素（11种，支持自定义浓度）
- **缓冲液**：10 mM MgCl₂、PBS磷酸缓冲液
- **PCR反应**：Taq/Phusion反应体系、dNTP Mix配制、琼脂糖凝胶
- **备忘录**：常用器皿与培养基/基质添加量速查表
- **全局搜索**：支持跨标签页搜索所有试剂、培养基和配方
- **液体/固体切换**：培养基支持液体和固体版本一键切换
- **实验 Protocol**：种子消毒接种、Bm 发病鉴定、种子包衣、双管无菌培养，以及玉米叶表/叶内微生物配对取样与 DNA 提取
- **输入校验**：阻止零除、负值、浓度倒置和无效总体积

## 包含的培养基

| 培养基 | 用途 |
|--------|------|
| PDA/PDB | *Bipolaris maydis* 培养与产孢 |
| MM最小培养基 | *Sphingobium* 碳源利用实验 |
| TSB/TSA | *Sphingobium* 常规培养 |
| LB/LBA | 通用细菌培养基 |
| R2A | 环境微生物专用低营养培养基 |
| KB | 假单胞菌及植物相关细菌培养 |
| 1/2 MS | 植物组织培养与种子萌发 |
| V8 | 卵菌和真菌培养基 |

## 使用方法

直接在浏览器中打开 `index.html` 即可使用，无需安装依赖或启动服务器。

如需运行自动测试：

```bash
node --test
```

## 技术栈

- HTML5
- CSS3（CSS 变量、Flexbox、Grid）
- Vanilla JavaScript（纯计算、共享数据与页面交互分离）
- Node.js 内置测试运行器

## 项目结构

```text
index.html          页面内容和结构
styles.css          页面样式
js/calculators.js   无 DOM 依赖的计算与校验函数
js/data.js          抗生素共享默认数据
js/app.js           页面交互和结果渲染
tests/              公式、数据一致性和 HTML 静态测试
```

## 数据与安全说明

页面中的默认配方用于实验计划和快速计算，不替代产品说明书、SDS、本单位 EHS 要求或实验室 SOP。标为“实验室内部 Protocol”或“待复核经验”的内容，应在正式实验前结合原始记录和具体材料批次验证。
