# ChemicalPrepare 可靠性重构设计

## 目标

在保持 `index.html` 可直接通过浏览器打开、无需构建和服务器的前提下，修复已确认的计算与数据问题，拆分单文件职责，增加自动测试、输入校验、来源分级标注和更可靠的搜索行为。

## 架构

- `index.html` 保留页面语义结构和实验内容。
- `styles.css` 承载现有样式。
- `js/calculators.js` 提供无 DOM 依赖的纯计算和输入验证函数，同时兼容浏览器与 Node 测试。
- `js/data.js` 集中维护抗生素默认值与来源状态。
- `js/app.js` 负责 DOM 交互、导航、搜索、渲染和错误展示。
- Node 内置测试运行器负责公式、数据一致性和静态 HTML 质量检查，不引入 npm 依赖。

## 已确认决策

- Streptomycin 默认母液 50 mg/mL、工作浓度 50 μg/mL，界面允许自定义。
- HgCl2 两个 Protocol 保留 2-3 min 与 10 min 的流程差异，并明确要求按流程和种子批次验证。
- 来源采用三级标注：外部来源、实验室内部 Protocol、待复核经验。
- 本阶段不加入复制配方、打印 Protocol 或配制记录导出。

## 行为要求

- 修复 12HEA 工作液单位换算、重复 V8 区块和重复 DOM ID。
- 计算器拒绝非有限值、负值、零除、目标浓度高于母液浓度和组分总体积超过终体积。
- 错误显示在对应结果区域，不再用 `|| 1` 静默替换非法输入。
- 搜索索引覆盖卡片全部可见文本，并在清除搜索后恢复原标签和卡片展开状态。
- 抗生素表格和两个计算器共享同一数据源。
- 页面在无法加载 Google Fonts 时仍可正常使用。
- README、页面更新时间和更新日志与实际功能同步。

## 验收

- `node --test` 全部通过。
- 静态检查确认 HTML 中不存在重复 ID。
- 浏览器打开本地页面无 JavaScript 错误。
- 手工验证 12HEA 标准案例输出 50.0 μL、0.1000% DMSO。
- 手工验证 Streptomycin 默认值和自定义浓度均能正确计算。
- 搜索 Protocol 步骤文本可命中，清除后恢复搜索前状态。
